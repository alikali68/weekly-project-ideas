# SnipNest

**Pitch:** A fast, searchable home for your code snippets — save, organize, and retrieve them with natural-language search, then share them as beautiful snippet cards.

## Problem & Target Users

Developers save snippets everywhere — scattered GitHub Gists, half-forgotten notes apps, dead Slack threads. Searching is painful (exact-match only), collections rot, and sharing a snippet with a colleague usually means pasting unformatted code into chat. **Target users:** solo developers, freelancers, and small dev teams (2–20 people) who reuse boilerplate, configs, regexes, and query patterns every day.

## Tech Stack

- **Next.js 15 (App Router) + TypeScript** — one codebase for the dashboard, public snippet pages, and API routes; SSR gives public share pages good SEO and rich link previews.
- **Tailwind CSS + shadcn/ui** — fast, consistent, professional UI; code highlighting via shiki themes that match the app's dark aesthetic.
- **PostgreSQL (Neon) + Prisma** — relational data with built-in full-text search; serverless Postgres keeps hosting cost near zero at MVP scale.
- **Clerk** — auth (email + GitHub OAuth) in hours instead of days; free tier comfortably covers MVP users.
- **pgvector on Postgres** — snippet embeddings live next to the snippet rows; no separate vector database to operate.
- **OpenAI-compatible embeddings API** — powers the natural-language semantic search ("the snippet that parses CSV dates with timezone handling").
- **Vercel** — zero-ops deployment with preview branches; fits the Next.js stack natively.

## Architecture Overview

Monolith-first: a single Next.js app serving the web dashboard, marketing pages, public snippet share pages (SSG/ISR), and API routes (server actions for mutations, route handlers for the public API). Snippet CRUD writes to Postgres; a background job (Vercel Cron / inngest) computes embeddings for new or edited snippets and stores the vectors via pgvector. Search fans out: keyword full-text first, then semantic re-ranking when the query looks like natural language. Share pages render server-side with OG images generated on the fly (satori) so links unfurl as styled code cards. An import pipeline (GitHub Gists, JSON export) runs as queued server functions so large imports don't block the UI.

## MVP Feature List (Prioritized)

1. **P0 — Snippet CRUD** with language auto-detect, tags, and collections; fast keyboard-first UI (Cmd+K command palette).
2. **P0 — Search**: instant full-text search plus natural-language semantic search over titles, descriptions, and code.
3. **P0 — Public share pages**: each snippet gets a permanent link with syntax-highlighted code and a copy button; auto-generated OG card image.
4. **P1 — Collections & starring**: group snippets into collections, star favorites, pin key snippets to the dashboard.
5. **P1 — Import**: one-click GitHub Gist import plus JSON/CSV import.
6. **P2 — Team workspaces**: shared collections with member roles (viewer / editor / admin).
7. **P2 — VS Code extension**: search your SnipNest from the editor and insert snippets via a personal API token.

## Data Model

- **User**: id, clerkId (unique), name, email, avatarUrl, plan ('free' | 'pro'), createdAt
- **Snippet**: id, userId (FK), title, description, code (text), language, isPublic (bool), slug (unique, for share links), embedding (vector, 1536 dims), forkedFromId (nullable FK → Snippet), viewCount, createdAt, updatedAt
- **Collection**: id, userId (FK), name, description, isPublic, createdAt
- **SnippetCollection** (join): snippetId, collectionId, position
- **Tag**: id, userId (FK), name (unique per user)
- **SnippetTag** (join): snippetId, tagId
- **Workspace**: id, name, ownerId (FK → User), plan
- **WorkspaceMember**: workspaceId, userId, role ('viewer' | 'editor' | 'admin'), joinedAt
- **ApiToken**: id, userId, name, tokenHash, lastUsedAt, createdAt

- **Week 1 — Core app skeleton:** Next.js + Clerk auth, Postgres/Prisma schema, dashboard shell with shadcn, snippet CRUD with shiki highlighting, tags + basic collections. Deploy to Vercel + Neon.
- **Week 2 — Search & sharing:** Postgres full-text search, embeddings job + pgvector semantic search, hybrid ranking, public share pages with satori OG images, copy buttons.

## Monetization Angle

Free tier: 200 private snippets, unlimited public snippets, semantic search included — a generous free tier grows the public catalog, which doubles as marketing. Pro ($8/mo): unlimited private snippets, team workspaces with unlimited members, custom share-page branding, and team sync in the VS Code extension. The public-snippet directory becomes an SEO moat: every shared snippet is an indexed landing page pulling in new users organically.
